# Moodle screenshots

- `connect.png`: real connection form, signed in with an injected local Stud.IP test account. No university credentials were used.
- `course-demo.png`: built-in demo course, labelled as sample data in the UI. No live Moodle data or tokens were used.

Captured through the shared browser preview at 1440 × 1050 CSS pixels.

To reproduce the course view, start the app, choose **Try demo**, open any course and add the **Moodle** tab. To reproduce the form, sign in to Stud.IP and add the same tab. The screenshots use the app's actual components without DOM modifications.
