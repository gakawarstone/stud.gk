# Moodle screenshots

- `connect.png` shows the Moodle sign-in form.
- `link-course.png` shows a selected Moodle course before the link is saved.
- `linked-course.png` shows the saved course link and its materials.

Captured directly in Electron at 736 CSS pixels wide with 2× pixel density. The full-size PNGs are 1472 pixels wide.

The screenshots use the app's UI with local Stud.IP and Moodle fixtures. The Moodle smoke test exercises the same flow from sign-in to linking a course.
