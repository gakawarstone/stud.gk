# UI conventions

- Hide visible scrollbars throughout the app, including nested scroll containers, dialogs, and standalone file preview HTML generated by the server.
- Preserve scrolling with the mouse wheel, touchpad, touch, and keyboard. Do not use `overflow: hidden` to hide a scrollbar on content that needs to scroll.
- Use `scrollbar-width: none` and `::-webkit-scrollbar` rules. The main app styles do not apply to standalone preview documents, so include these rules in their own styles too.
