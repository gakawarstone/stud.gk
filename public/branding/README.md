# Варианты логотипа Stud.GK

Открой `/branding/index.html` при запущенном приложении. Галерея работает и как отдельный HTML-файл. Кнопка «Примерить» меняет только образец шапки в галерее.

Первый раунд содержит десять SVG рядом с галереей. [Второй раунд](round-2/index.html) с вариантами 11–20 продолжает выбранные №2, №7 и №10, основной фаворит — №7. Все рисунки созданы для Stud.GK из векторных контуров, без шрифтов и внешних зависимостей. `viewBox="0 0 64 64"`, прозрачный фон, основной цвет задаётся атрибутом `color`. При вставке SVG в HTML его можно переопределить через CSS `color`.

Выбранные направления первого раунда: **07 · Траектория S** как фаворит, **02 · Складка S** и **10 · Росчерк sg**. Во втором раунде они доступны для прямого сравнения с новыми знаками.

В шапке приложения установлен доработанный **№12 · Модульный маршрут** вместо первой буквы S: знак вместе с `tud.GK` образует единое название. Размер надписи 18 px, на узком экране 17 px. Для скринридеров сохранено полное имя Stud.GK.
