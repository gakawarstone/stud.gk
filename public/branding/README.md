# Stud.GK logo concepts

Open `/branding/index.html` while the application is running. The gallery also works as a standalone HTML file. The "Try it" button changes only the sample header in the gallery.

The first round contains ten SVGs next to the gallery. The [second round](round-2/index.html), with concepts 11 through 20, develops the selected concepts #2, #7, and #10, with #7 as the main favourite. All drawings were created for Stud.GK using vector paths, without fonts or external dependencies. They use `viewBox="0 0 64 64"` and a transparent background. The primary color is set by the `color` attribute. When embedding an SVG in HTML, you can override it with CSS `color`.

The selected first-round concepts were **07 · S route**, the favourite, **02 · Folded S**, and **10 · sg script**. They are available in the second round for direct comparison with the new marks.

The application header uses the refined **#12 · Modular route** in place of the initial S. Together with `tud.GK`, the mark forms the full name. The wordmark is 18 px, or 17 px on narrow screens. Screen readers still receive the full name Stud.GK.
